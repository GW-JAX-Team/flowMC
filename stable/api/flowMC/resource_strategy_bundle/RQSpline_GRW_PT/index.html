RQSpline GRW PT

RQSpline_GRW_PT_Bundle ¤

Bases: ResourceStrategyBundle

A bundle that uses a Rational Quadratic Spline as a normalizing flow model and Gaussian Random Walk as a local sampler.

The main difference between this and the RQSpline_GRW_Bundle is that this bundle uses an additional parallel tempering step to sample from the target distribution.

In this bundle, the sampler requires an additional logpdf function that is the prior distribution. If the log prior is not provided, it will be set to 0.
